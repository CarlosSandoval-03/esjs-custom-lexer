Detailed Description

Lightweight, non-owning view of a single lexeme in the input buffer.

The lexer does not copy lexeme text; instead it stores a pointer directly into the Buffer's internal data array together with the length of the match. The Buffer must remain live and unmodified for as long as any Token referencing it is in use.

For TOKEN_STRING and TOKEN_REGEX the delimiters (quotes or slashes) are excluded: lexeme_start points to the first content character and lexeme_length counts only the content bytes.
