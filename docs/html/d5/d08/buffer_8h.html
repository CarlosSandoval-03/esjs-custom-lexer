Detailed Description

Lazily-loaded, dynamically-growing input buffer for the lexer.

The Buffer abstracts the underlying FILE* stream so that the scanner and DFA can perform arbitrary lookahead and backtrack freely by re-reading already-loaded bytes via buffer_get(). Data is read on demand: bytes are fetched from the stream only when a position beyond the currently loaded range is accessed.

Memory management:

  • buffer_init() sets the initial empty state (no heap allocation yet).
  • buffer_get() triggers lazy loading when necessary, growing the internal array if capacity is exhausted.
  • buffer_destroy() releases the heap-allocated data array and resets all fields to safe defaults.

The caller is responsible for keeping the FILE* open for as long as the Buffer is in use.

int buffer_get ( Buffer * buf,
const size_t pos )

Returns the byte at absolute position pos, loading from the stream if necessary.

If pos is within the already-loaded range the byte is returned immediately. Otherwise the buffer reads ahead until the position is covered, growing the internal array as needed. Returns EOF when pos is beyond the end of the input stream.

Parameters
bufBuffer instance. Must not be NULL.
posZero-based byte offset into the input stream.
Returns
The byte at pos cast to unsigned char and widened to int, or EOF if the position is past end-of-stream.

Returns the byte at absolute position pos, loading from the stream if necessary.

If the position is beyond the end of the stream, EOF is returned and the buffer is not modified. The return type is int (not char) to match the convention of fgetc() and allow unambiguous EOF detection.
