Detailed Description

Cursor state over the input Buffer.

The Scanner owns no memory itself; it holds a pointer to a Buffer and tracks the current read position together with the associated source coordinates. Copying a Scanner (struct assignment) creates an independent cursor that can be advanced separately — this is exploited by scanner_match_longest_after() to probe both the default and regex interpretations without consuming input until the winner is chosen.
